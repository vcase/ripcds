Optional bundled fre:ac files live here.

For a one-step installation, place the fre:ac portable Windows distribution in
this folder so that this file exists:

    resources/freac/freaccmd.exe

The application checks this bundled copy first, then the usual fre:ac install
locations, then PATH. If freaccmd.exe is not bundled, the user can point RipBook
at an installed fre:ac in the Settings section.
